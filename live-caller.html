How the live comparison worked

The same saved voice-agent runtime, Nemotron assistant, hosted ASR, Magpie agent voice, retail tools and native task checks ran in both versions. GPT-5.5 generated new caller replies, spoken through Gemini Flash TTS. Matching task/preset pairs used seeds 301, 302 and 303. All outcomes were retained.

The original version forwarded raw ASR. The corrected version changed only these previously frozen name forms: Covax / Kovax / coax → Kovacs and Dakey / Dikey / Dekey / Doki → Daiki, in identity context. Other words, spelled letters, digits, audio boundaries and finalization flags were preserved. No LM was trained.

The native caller reacts to the agent’s transcript fragments synchronized with played audio. It does not independently transcribe the agent’s voice. Caller speech still passes through actual TTS, telephone processing and the agent’s ASR.

Pilot and audio checks

Six initial calls revealed additional name forms missed by the narrow rules. All six pilot scores were 0; they remain separate from the main results. Blind Gemini and GPT Transcribe checks of exact delivered-audio clips informed the revised word list before validation. “Kovac,” “Cobax” and unspelled “May/Mei” remained ambiguous and were excluded from correction.

4 provider startup failures were retained without task scores and replaced once. Valid task failures were never retried. Full recordings, raw/forwarded ASR, tool calls, native scores and audio-check responses are retained locally.

How far the result applies

  • This tests selected name corrections, not a trained language model or a new WER result.
  • The sample is small. Matched seeds do not make the generated audio or dialogue identical; timing and provider variability remain.
  • Correction-audio references are machine checked, with uncertainties preserved. No human-certified golden reference is claimed.
