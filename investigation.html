What the evidence shows

  • 025 control · Wrong refund action. ASR says “Amex … not PayPal”. The agent nevertheless processes the return to PayPal. Replaying that tool call reproduces the database-score failure.
  • 088 regular · Agent email reconstruction. ASR retains the name and all email digits. The agent adds an extra dot before the digits; removing only that dot makes the local lookup succeed.
  • 099 regular / 105 control · Correct letters were available. ASR includes the required explicit spelling, but the agent uses a conflicting name or literal spaced letters in the lookup. Better transcription alone is not an established remedy.
  • 064 regular · Wrong tool for the order state. After successful lookup, the agent tries a delivered-order exchange on a pending order, then cancels it rather than modifying it.
  • 088 control · Low WER, stalled voice flow. With just 0.67% provisional WER, no tool executes. Caller-visible ticks contain short/overlapping assistant fragments rather than full emitted paragraphs. Playback and turn-taking need investigation; the precise software cause is not isolated.

Task scores need careful interpretation

  • 025 regular: native score 1 reflects an unchanged database and no judged requirements. No order mutation or executed transfer is recorded. This pass does not independently establish full customer-goal completion.
  • 105, both presets: the reference exchange itself fails for insufficient gift-card balance. An unchanged DB can therefore pass the database component even though no exchange occurred. The judged exchange requirement fails. Review task feasibility before using it for LM task-score claims.
  • 035 and 106: the first offered email is intentionally invalid even with oracle spelling; an alternate address is valid. An initial failed lookup is not itself proof of ASR error.

Native rewards combine final database state and judged requirements where present. Example tool-call matches are diagnostic; they are not a required exact sequence. All original scores are preserved.

Current priorities after the live follow-up

  1. Resolve agent tool-use and voice-flow blockers; selected name corrections produced no task passes.
  2. Finish human audio review before claiming golden WER.
  3. Test any later LM on separate training text and identical frozen audio; task-score benefit remains unproven.

The judgments do not establish that ASR correction alone would rescue three tasks, or that LM training would help. The 8.41% WER remains provisional; human-verified golden WER is pending. Do not substitute hidden scenario answers for what is audible.
